## 🔬 About My Research
I am a **Computer Science & AI Researcher** dedicated to bridging the gap between theoretical machine learning models and high-performance hardware execution. My core focus lies in **Deep Neural Network Optimization**, **Parallel Matrix Computation**, and **Scalable AI Systems**.
```math
\mathcal{L}_{\text{total}}(\theta) = \underbrace{\mathbb{E}_{(x,y)\sim \mathcal{D}} \left[ \ell(f_\theta(x), y) \right]}_{\text{Empirical Risk}} + \underbrace{\lambda_1 \|\theta\|_1 + \lambda_2 \|\theta\|_2^2}_{\text{Sparse Regularization}} + \underbrace{\gamma \cdot \text{KL}(q(\cdot|x) \,||\, p(\cdot))}_{\text{Information Divergence}}
```
### 📌 Current Focus & Research Directions
- 🌌 **Neural Architecture Design**: Exploring attention mechanisms, transformer variants, and lightweight convolutional models using **PyTorch** & **TensorFlow**.
- ⚡ **GPU Acceleration & Low-Level Kernels**: Writing custom CUDA C/C++ operators to accelerate matrix multiplications and high-dimensional tensor contractions.
- 🧪 **Statistical Data Analytics**: Extracting patterns and latent structures from complex scientific datasets with **Scikit-Learn**, **NumPy**, and **Pandas**.
- 📊 **Insightful Visualizations**: Designing publication-grade scientific plots using **Matplotlib** and **Seaborn**.
- 🌐 **Model Deployment & Microservices**: Building low-latency REST APIs for real-time inference using **Flask**.
